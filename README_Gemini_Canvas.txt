Food Discovery - Gemini Canvas image assets

This ZIP contains 10 real JPG image files under images/dishes/ and mapping CSV/JSON.
Unzip the archive and copy the images directory into the website project public root.
The website should use image_url from the mapping (e.g., images/dishes/D01.jpg).
If using React/Vite, put images/dishes/ inside public/ so /images/dishes/D01.jpg resolves.
If using plain HTML, keep images/ next to index.html.
Uploaded images are NOT automatically accessible as paths inside a Gemini Canvas preview. The website project must actually contain these files or use hosted image URLs.
Do not use the images for D11-D25; use placeholders.
D07, D08, D10 are lower-resolution crops from a montage; consider replacing them for final production.
