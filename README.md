# Food Discovery｜食物探索

> 認識食材，探索料理，建立自己的飲食文化。

單檔網頁應用（`index.html`），直接用瀏覽器開啟即可使用，不需要安裝或建置。

## 功能

- **首頁**：「今天，你想吃什麼？」主視覺、今日飲食靈感、探索不同料理文化
- **食物探索**：依食材與用餐情境推薦料理，或瀏覽全部 25 道跨國料理
- **飲食靈感**：課程展示用的虛構創作者與示範作品
- **食材圖鑑**：30 種食材的風味、搭配與相關料理
- **我的飲食日記**：記錄每一餐、加照片與標籤、近 7 日回顧，並可匯出 PNG 分享卡（資料存在瀏覽器 localStorage）

## 技術

- Tailwind CSS（CDN v3）、Lucide Icons、Noto Sans TC / Inter
- 原生 JavaScript 狀態管理，網址 `#home`、`#explore` 等對應各頁
- 支援手機版（底部彈出面板、返回鍵、分享到相簿）

## 檔案說明

| 檔案 | 說明 |
|---|---|
| `index.html` | 網站本體 |
| `D01.jpg`～`D10.jpg` | 料理照片（網站透過 GitHub Raw 網址讀取） |
| `food_discovery_claude.md` | 開發交接備忘錄，含照片與料理的對照表 |

> 照片檔名是依舊版料理清單編號，與網站內的料理編號不同，正確對照請見 `food_discovery_claude.md`。

## 線上瀏覽

到儲存庫 **Settings → Pages**，選擇 `main` 分支、根目錄後儲存，即可透過 GitHub Pages 開啟網站。
